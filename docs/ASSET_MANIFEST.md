# Asset Manifest — Malaysia: The Mandate

**Status:** Phase 1 deliverable. Documents what ships today, then defines the asset contract for Phases 2–8.
**Rule:** no code may reference an asset path that is not listed here or resolvable through a documented drop-in chain.

---

## 1. How assets are addressed today

Two mechanisms exist in code; both must survive the overhaul.

### 1.1 Direct paths

```ts
// src/data/art.ts
SCENE_SVG = {
  office:   "/art/scene-office.svg",
  chamber:  "/art/scene-chamber.svg",
  treasury: "/art/scene-treasury.svg",
  ops:      "/art/scene-ops.svg",
  flood:    "/art/scene-flood.svg",
}
MENU_ART = "/art/menu-putrajaya.svg"
```

`artForScene(location)` maps a narrative location string to a `SceneKey` (`data/art.ts:23–35`). Scene keys are **stable identifiers** and part of the narrative contract.

The office hub and the three masterhead screens reference files explicitly:

| File | Referenced by |
|---|---|
| `/art/scene-hub.svg` | `pages/Office.tsx:90` |
| `/art/scene-chamber.svg` | `pages/Parliament.tsx:31`, `data/art.ts` |
| `/art/scene-treasury.svg` | `pages/Economy.tsx:29`, `data/art.ts` |
| `/art/scene-ops.svg` | `pages/Security.tsx:26`, `data/art.ts` |
| `/art/menu-putrajaya.svg` | `pages/MainMenu.tsx:112` |

### 1.2 Drop-in chains (zero code change)

```
Scene painting:   public/art/painted/<sceneKey>.webp | .png | .jpg
Hub painting:     public/art/painted/hub.webp | .png | .jpg
Portrait:         public/portraits/<characterId>.webp | .png | .jpg
                  (manual override: PORTRAITS map in src/data/portraits.tsx:19)
```

Resolution order: manual entry → convention files → shipped fallback (vector scene / 64×64 bust / generic figure). A missing file is silent and must stay silent. `PaintedScene` and `Avatar` implement this today; `public/art/painted/` does not exist yet, which is valid.

## 3. Raster pipeline (current behaviour to preserve)

```
SVG file ──► Image ──► canvas at full resolution ──► canvas at 1/3 with smoothing off
                                                        │
                                          image-rendering: pixelated
```

- `src/data/pixelate.ts` — two-pass rasteriser, cached per `src@WxH`.
- `PixelScene` — smooth fallback underneath until the raster resolves.
- `MalaysiaMap` — serialises the chart to an SVG string, rasterises 1200×640 → 400×213, caches in module scope (`staticPixelUrl`).
- `Avatar` — 64×64 canvas, `pixelated` only at `xl`/`stage`.

From Phase 2 the pipeline gains an **authored-pixel** branch: if `public/art/pixel/<id>.png` exists, use it directly at native size (no rasterisation). The downsampler remains for legacy SVGs and painted drop-ins.

## 4. ID conventions

Stable IDs are dotted, lower camel after the namespace. They must not change once shipped.

| Namespace | Pattern | Example | Stability |
|---|---|---|---|
| Scene | `scene.<key>` | `scene.chamber` | Narrative contract |
| Environment | `env.<room>` | `env.officeHub`, `env.cabinetRoom` | New |
| Character | `<characterId>` (from data) | `finance` | Save/data contract |
| Sprite | `sprite.<characterId>.<state>` | `sprite.home.neutral` | New |
| Bust | `bust.<characterId>` | `bust.finance` | New |
| Prop | `prop.<object>` | `prop.clock`, `prop.folders` | New |
| Map | `map.<scope>` | `map.federation`, `map.asean` | New |
| Party | coalition id | `ph`, `bn`, `gps`, `grs`, `warisan`, `pn`, `others` | Data contract |
| State | state id | `selangor`, `kuala-lumpur` | Data contract |
| Outlet | outlet id | `peninsula`, `borneo`, `sinar` | Data contract |

File paths are derived from IDs, not the reverse.

## 7. Manifest schema (to be created in Phase 2)

Proposed file: `src/data/asset-manifest.ts`. Presentation-only; no engine import.

```ts
export type AssetKind =
  | "environment"
  | "scene"
  | "sprite"
  | "bust"
  | "prop"
  | "map"
  | "icon"
  | "keyart";

export interface AssetEntry {
  /** Stable, dotted ID. Never reused, never renamed. */
  id: string;
  kind: AssetKind;
  /** Path from /public, e.g. "/art/pixel/env-office-hub.png". */
  src: string;
  /** Native pixel size. */
  width: number;
  height: number;
  /** Intended display multiplier (integer). */
  scale: 1 | 2 | 3 | 4;
  /** Optional painted/drop-in alternatives, tried in order. */
  candidates?: string[];
  /** Character or scene this belongs to, when relevant. */
  owner?: string;
  /** Provenance for licence review. */
  source: "authored" | "vector" | "ai" | "public-domain";
  licence: string;
  /** Optional note shown in dev tooling. */
  note?: string;
}

export interface AssetManifest {
  version: 1;
  assets: AssetEntry[];
}
```

Validation rules (a small script, not runtime):

1. Every `src` exists in `public/`.
2. Every ID is unique.
3. Every `kind: "scene"` ID matches a `SceneKey` in `data/art.ts`.
4. Every `kind: "bust"`/`"sprite"` `owner` matches a character ID in `data/characters.ts`.
5. Every `kind: "map"`/`"prop"` referenced by a page is registered.
6. Native size matches the file's real dimensions.

## 8. Provenance and licensing

| Source | Licence note | Required record |
|---|---|---|
| Original project art | Project copyright | `source: "authored"` |
| Generated with AI | Model terms + project policy | model, prompt reference, date, reviewer |
| Natural Earth geometry | Public domain | already credited in `geo-paths.ts` header and README |
| Fonts | Fraunces, Public Sans — SIL Open Font License, bundled via Fontsource | `package.json` |
| Lucide icons | ISC | `package.json` |
| Gamedev skills in `.opencode/skills/` | Apache-2.0, third-party | `LICENSE`/`NOTICE` already present — do not alter |

Never add an asset without a provenance row. Never add a remote URL at runtime.

## 9. Gaps and risks

| Gap | Impact | Phase |
|---|---|---|
| No authored pixel plates — all art is downsampled vector | The headline visual promise is unmet | 2 |
| No character sprites or expression states | Exploration and dialogue cannot show people in rooms | 3 |
| No Cabinet/Meeting/Press environments | Three directive modes have no venue | 6 |
| No `public/art/painted/` directory | Drop-in chain is documented but unexercised | 2 (create empty, with README) |
| No manifest | Asset drift, dead files, broken paths | 2 |
| Map tokens carry no state-shape fill | Selection is readable but not tactile | 5 |
| Raster work runs on the main thread | Jank on low-end phones as scenes multiply | 2 (measure) / 8 (optimise) |
| Existing SVGs use gradients | Pixel result has unintended ramps | 2 onward, per plate replaced |
| Hub hotspots hard-coded to 1440×760 | Any redraw risks misalignment | 2 (anchor test) |

## 10. Acceptance gate for every asset commit

1. File exists at the documented path; size matches the manifest.
2. Native canvas is on spec; displayed at an integer scale.
3. `npx.cmd tsc --noEmit`, `npm.cmd test` (8/8), `npm.cmd run build` green.
4. Screenshot at 1440×900 and 390×844 reviewed.
5. No console errors; no 404s in the network panel for optional drop-ins.
6. Provenance recorded; no real person, party logo or crest.
