## What will NOT change (hard rules)

- `src/engine/**`, `src/types/game.ts`, character IDs and names, event/option IDs, the 22
  routes, storage keys, EN/MS key parity.
- The portrait fallback chain: raster drop-in -> authored bust -> generic.
- The Federal Document palette tokens; `scripts/audit-contrast.mjs` all-PASS; no literal hex in
  components (art scripts may define palette ramps as data).
- Reduced-motion honouring, 44 px touch targets, keyboard + ARIA parity, fiction labels.
- The 15 legacy events stay byte-identical; saves keep loading.
- Assets stay reproducible: every sprite/portrait/icon generated by scripts, registered in
  `src/data/asset-manifest.ts`, `npm run check:assets` green.

## Phases (commit + tag `v3a-phase-N`; stop after each with before/after screenshots)

### Phase 1 — this step
Plan, decisions, `scripts/contact-sheet.ts`, BEFORE sheet + screenshots. **Done.**

### Phase 2 — generator, bodies, faces, expressions
Files: `src/data/pixel-portraits.ts` (rewritten as layered generator + palette ramps), new
`src/data/cast-visuals.ts` (per-character body/clothing/signature-colour/age/props data),
`scripts/build-sprites.ts` (64x96 sheets + new frame families), `PixelSprite.tsx` (integer
scale, new frames), self-checks (expression delta >= 3%, silhouette IoU < 0.8 pairwise,
palette-limit audit), contact sheet AFTER + review. PM avatar data stays additive.

### Phase 3 — culture wardrobe, props, poses, portraits
Files: cast-visuals expansion (tudung/hijab construction, songkok, kopiah, batik, kebaya,
baju Melayu, sherwani, sarong; props: folder, phone, tablet, cane; poses: stand, clasped,
desk), `NewGame.tsx` character-select rebuild (same fields, same saved shape), 96x96 portrait
busts with 6 expressions, contact sheet + in-game screenshots.

### Phase 4 — UI kit foundation
Files: `src/styles/index.css` (kit tokens + 9-slice frames), `src/components/ui/*`
(PixelPanel, PixelButton states, segmented gauges with delta arrows, type scale — kickers to
>= 12 px readable colour, Silkscreen at integer sizes only), controls (select/toggle/slider/
checkbox/radio/scrollbar), `src/engine/sound.ts` (Web Audio kit, D-21) + Settings mute/volume.
Applied to the shell (ipad/*, GameLayout) first.

### Phase 5 — main menu + title flow
Files: `MainMenu.tsx` (pixel emblem lockup replacing the striped lapel, first-visit title-card
"press any key" moment, hotkeys Up/Down/Enter/N/C, focus cursor, save card on Continue,
Credits + version), `scripts/build-menu-plate.mjs` (layered parallax key art: sky, skyline,
dome, boulevard, foreground; stars, clouds, window lights, lamp flicker, day-dusk tint; static
frame under reduced motion), NewGame character-select polish.

### Phase 6 — apply the kit everywhere + regression
Files: remaining screens on the kit, HUD/stat icons, scanline/dither Settings option (off by
default), Midnight theme pass, performance (animation budgets), full regression: tsc, 22/22 +
new art checks, check:assets, build, zero console errors, screenshots at both gates, contact
sheet final review.
